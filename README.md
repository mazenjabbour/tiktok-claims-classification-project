# TikTok Claims Classification Project

An end-to-end data science portfolio project focused on inspecting, analyzing, visualizing, and modeling TikTok video data for claims classification using Python, Tableau, statistics, and machine learning.

---

# Project Overview

This repository documents my practical work throughout the Google Advanced Data Analytics Professional Certificate using a fictional TikTok dataset.

The project follows a complete analytics and machine learning workflow, progressing from data understanding and exploratory analysis to statistical testing, predictive modeling, and advanced machine learning evaluation.

The project covers:

* Data understanding and preparation
* Exploratory Data Analysis (EDA)
* Data visualization and storytelling
* Statistical hypothesis testing
* Logistic regression classification
* Random Forest and XGBoost modeling
* Model evaluation and interpretation
* Ethical AI considerations
* Machine learning workflow development

---
